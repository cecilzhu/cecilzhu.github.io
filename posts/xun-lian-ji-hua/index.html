（胸肌 + 腹肌）训练计划

慢才后生2026-09-112026-09-11

[TOC]

适用对象：偏瘦、略有小肚子（”瘦胖子”体质），健身初学者，时间有限，主要依靠徒手，健身房仅在突破期使用。

核心原则：动作质量 ＞ 次数；每组做到”动作即将变形”即停；先加次数打基础，再加负重/变式突破。

一、通用规则（贯穿全程）

项目规则
训练频率隔天练（如周一/三/五），肌肉在休息时生长，不可天天练同一肌群
组间休息俯卧撑等力量动作：90秒～2分钟；卷腹等小肌群：45～90秒。禁止休息 10～15 分钟（肌肉冷却、效率骤降）
每组强度做到”还能勉强完成最后一个、但下一个会塌腰/借力”即停 = 发抖力竭，不硬凑数字
组间递减第1组10个、第2组8～9、第3组7～8 属正常，不必每组都一样
呼吸节奏口诀：用力时呼气，放松时吸气。俯卧撑推起呼气；卷腹起身呼气；平板支撑全程均匀呼吸，绝不憋气
动作标准俯卧撑：胸口离地一拳即可，禁止下巴触地（伤颈椎）；肘与身体呈约45°，禁止向两侧90°撇肘（伤肩+练不到胸）。想象”腋下夹一张纸”
饮食关键戒含糖饮料/油炸/夜宵，晚餐碳水减半。腹肌主要在厨房练出来，体脂不涨腹肌才显形
记录方式每次记下每组次数，下次争取每组 +1

二、基础训练计划（第 1～2 个月）

本阶段目标：建立动作模式、打好基础。只加次数，不加负重。

星期训练内容
周一 / 周三 / 周五见下方 A 组
周二 / 周四 / 周六休息或散步（可做墙壁天使+门框扩胸，3分钟）
周日完全休息

A 组：胸 + 核心（约 30 分钟）

顺序动作组数×次数休息要点
1标准俯卧撑4组 × 8～1290秒～2分钟胸口离地一拳，肘收45°，不做下巴触地
2卷腹3组 × 15～2045～90秒慢起慢落，起身呼气
3反向卷腹3组 × 10～1545～90秒躺平抬腿，用腹肌把屁股抬离地面
4平板支撑2组 × 30～45秒60秒全身均匀呼吸，不憋气（护腰稳核心，非练腹肌主力）

每日必做（防驼背，3分钟）

动作做法呼吸组数
墙壁天使背靠墙，双手屈肘90°贴墙，向上滑直再收回打开吸气，收回呼气3组×10次
门框扩胸双手抓门框，身体前倾拉伸胸肌保持自然深呼吸3次×15～30秒

三、进阶判定规则（何时升级）

核心逻辑：当某一动作能”连续两次训练都轻松完成目标次数上限“ → 升级。

阶段策略触发条件（连续2次轻松完成）
阶段一（1～2月）只加次数俯卧撑 12次、卷腹 20次、反向卷腹 15次
阶段二（2～4月）加负重 / 换更难变式负重下 8～12次标准
阶段三（4～8月）负重+变式循环持续提高负荷

为什么先加次数后加负重：初期神经适应快，加次数即进步、且安全；次数到 15+ 后增肌效率下降（见第四部分”次数上限”），必须转入负重。

四、进阶增强计划（阶段二、三）

重要概念：次数的”有氧上限” —— 单组做 20～30 次以上时，主要刺激慢肌纤维（耐力），快肌纤维（增肌主力）已不工作，训练从”增肌”变成”有氧耐力”。想增肌，每组保持在 6～15 次区间最有效，超过就加负重/换变式。

俯卧撑进阶路径

阶段动作每组次数何时进阶
1标准俯卧撑10 → 12连续2次轻松做12个
2标准俯卧撑 + 背包3kg8 → 10连续2次轻松做10个
3标准俯卧撑 + 背包5kg6 → 8连续2次轻松做8个
4下斜俯卧撑（脚垫高）8 → 12连续2次轻松做12个
5下斜 + 背包3kg6 → 10循环往复

卷腹进阶路径

阶段动作每组次数何时进阶
1标准卷腹15 → 20连续2次轻松做20个
2负重卷腹（抱3kg）12 → 15连续2次轻松做15个
3负重卷腹（抱5kg）10 → 12连续2次轻松做12个
4悬垂举腿 / 躺姿举腿8 → 12连续2次轻松做12个

反向卷腹进阶路径

阶段动作每组次数何时进阶
1标准反向卷腹10 → 15连续2次轻松做15个
2反向卷腹 + 慢放（3秒下落）8 → 12连续2次轻松做12个
3悬垂提膝（挂单杠）6 → 10连续2次轻松做10个

阶段二起新增的补强动作

动作作用组数×次数
俄罗斯转体侧腹/腹斜肌3组×20（每侧10）
腹肌轮（跪姿）腹肌深度刺激，杀手锏3组×8～12
负重卷腹突破腹肌平台3组×10～15

五、健身房”突破工具”使用节点

日常靠徒手省时间，仅在必要时去健身房 30～40 分钟补负荷。

触发信号推荐动作组数
标准俯卧撑 3×12 轻松、胸围几周不变哑铃卧推 / 上斜哑铃推3组×8～12
想雕下胸/外沿双杠臂屈伸（前倾）3组×8～12
上胸弱上斜哑铃卧推（凳30～45°）3组×8～12
胸中缝拉伸感差哑铃飞鸟3组×10～15

六、分阶段训练效果预测

前提：严格执行计划 + 饮食干净（不节食、不暴涨体脂）。体脂率决定腹肌可见度。

阶段时间能力变化外观变化
适应期第1～2周俯卧撑从勉强10个变稍轻松；卷腹灼烧感更强几乎看不出外观变化（打地基）
初步变化第3～4周俯卧撑进步到12～15个；卷腹稳定20个晨起小肚子明显变小；T恤下胸口/肩线若隐若现；放松态仍有小肚子但更紧致
肉眼可见第2～3个月俯卧撑15～20个/组胸肌：上胸内侧出现浅轮廓线；腹肌：收紧时上面两块若隐若现；体态因墙壁天使而挺拔、视觉显高
稳定成果第3～6个月可进入负重/变式阶段胸肌：明显下沿轮廓，衬衫被胸口撑起；腹肌：收紧时六块清晰、放松时上四块可见；小肚子几乎消失
雕刻期第6～9个月负重卷腹、悬垂举腿等进阶动作六块腹肌在多数状态下清晰
细节期9个月以上高负荷循环六块稳定；八块取决于基因（腱划数量天生固定，无法练出），目标设为”清晰六块”更现实

关于”放松状态下的小肚子”

  • 人类腹腔有内脏，站立时受重力影响必然微微凸起，即使健身模特放松时下腹也有弧度，属正常解剖结构。
  • 合理目标：收紧时线条清晰，放松时平整不突兀。追求”放松也完全平坦”需体脂极低（女<18% / 男<10%），有害健康与生活品质，不建议。

七、计划速查总结

维度结论
动作选择俯卧撑（胸）、卷腹（腹）、反向卷腹（下腹）、平板支撑（护腰）、墙壁天使（防驼背）✅；仰卧起坐 ❌
呼吸用力呼气、放松吸气；墙壁天使”打开吸气、收回呼气”
休息力量90秒～2分钟，小肌群45～90秒；严禁10～15分钟
进阶次数到上限（轻松12～15）→ 加负重/换变式 → 负重下再加次数，循环
次数上限单组＞20～30次变有氧，增肌保持 6～15 次区间
健身房突破期才去，日常徒手省时间
饮食戒糖油夜宵、晚餐碳水减半，腹肌靠饮食显形
预期1个月初步、3个月脱衣有肉、6个月稳定六块轮廓

核心提醒：动作标准永远优先于次数与重量，循序渐进、坚持记录，4～6周即可见明显变化。
